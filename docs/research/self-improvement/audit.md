## Must fix

1. **Re-point the focus-vs-completeness citation.** In "Library growth hurts through selection, not context length", the sentences "Focused Skills with at most three modules outperform larger or exhaustive bundles" and "Comprehensive prose is essentially flat while focused documentation yields larger aggregate lift (+0.7 pp vs. +19.0/+21.5 pp)" sit under the More Skills, Worse Agents link (arxiv 2605.24050) and are **not in that paper**. Both are SkillsBench (arxiv 2602.12670 — abstract and §F/Appendix F). Fix: give each sentence its own citation to 2602.12670, and keep 2605.24050 for the 21% / context-overhead pair only.
2. **Cut or re-cite the sabotage number.** "sabotaging a description 'the way a careless PR would' dropped a case 'from 1.00 to 0.56'" is attached to the trigger report, which contains only the 88%/6-of-29 table and the 80%/10% targets — no sabotage experiment, no 0.56. Either supply the URL of the sabotage write-up on the same site, or delete the clause; as written it is the kind of citation a reviewer will spot-check first.
3. **Verify the background-pass trigger.** `_iters_since_skill >= 10` is not in `agent/background_review.py`, and the "docs say '~every 10 agent turns' … a doc/code mismatch" parenthetical rests entirely on that symbol. Find the module that owns the counter and cite it (or restate as "fires after a fixed number of tool iterations, threshold set outside background_review.py") — otherwise the one claim the report uses to argue that *mechanism, not wording*, sets write volume is unsourced.
4. **Keep the prompt-surface links pinned.** `surfaces.json` on `main` now reports `"volatile": 1264–1269`, not 1528; the 1,528 figure is only true at the pinned commit `1f91da2`. The report's link is pinned (correct) — but any later "refresh the links to main" pass would silently falsify the 1,040-token attribution, so add a "measured at this commit" note beside the number.
5. **Minor:** the index measurement is stated as "~4,166 characters"; the `<available_skills>` block measures 4,216 chars (4,071 for the 53 rows alone). Either figure is defensible, but say which boundary was counted.
