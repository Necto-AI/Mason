## Must fix
1. **The Home Assistant trust quote points at the wrong page.** [58] goes to `/marketplace/guides/integrations/`, which does not contain "made and supported by you" anywhere. Repoint it to `https://contributors.home-assistant.io/marketplace/`, where the sentence is verbatim ("Everything shared this way is made and supported by you, not by the Home Assistant project. Users see a warning that says so before they install anything from the Marketplace."). Keep the guides page if the "built the same way as core" point is wanted — but that is [57]'s job already.
2. **"CVSS-10" is not the advisory's number.** GHSA-864f-rcv7-6rh4 rates it "Severity: critical" and lists "Affected versions <=7.0.0"; no numeric CVSS score appears on the page. Write "a critical-severity guest→host escape in every version through 7.0.0" (or cite a source that prints 10.0). The quote and the affected range stand as written.
3. **"the client SHOULD re-list" overstates MCP's normative text.** [73] makes the *server*'s notification a SHOULD; the client's re-list is only in the message-flow diagram. Reword to "the spec's message flow has the client re-issue `tools/list` after `tools/list_changed`", or drop "SHOULD" for the client.
4. **Optional, not an error:** for the credentials-file finding, cite Anthropic's own admin doc ([46] — "Permission rules and `PreToolUse` hooks apply to Claude's tool calls, not to a mod's `$.fs` and `$.process` calls") beside or instead of Pluto Security, and keep Pluto for the measured reproduction ("No prompt appeared. No permission was asked"). Primary plus reproduction is stronger than secondary alone.
