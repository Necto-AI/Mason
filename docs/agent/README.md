# The reference

What this machine is, and how the parts you cannot see work. Read the page your question is about; none of it is your
memory — `agent/profile.md`, `agent/log/` and `agent/skills/` are.

- `events.md`: what wakes you besides a person, and how to read a fire.
- `env.md`: the machine your tools run on, and where your files are.
- `connectors/<name>.md`: one page per connector this home is granted.

These pages ship with mason. They are not mounted, and an edit here is not yours to keep: what should survive belongs in
`agent/skills/`, which is. An integration's own markdown pages are MCP resources, read with `mcp_read_resource`.
